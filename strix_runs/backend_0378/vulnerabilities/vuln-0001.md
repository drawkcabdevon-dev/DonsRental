# Wildcard CORS Policy in FastAPI Application

**ID:** vuln-0001
**Severity:** MEDIUM
**Found:** 2026-08-25 03:38:57 UTC
**Target:** /workspace/backend
**Endpoint:** /
**CWE:** CWE-942
**CVSS:** 5.3
**Fix Effort:** Low

## Description

The FastAPI application at `backend/main.py` is configured with a Cross-Origin Resource Sharing (CORS) policy that allows all origins (`'*'`). This permissive setting can lead to security vulnerabilities if sensitive data is handled, as it allows any domain to make requests to the API, potentially bypassing same-origin policy protections.

## Evidence

The `semgrep` scan identified the `allow_origins=["*"]` configuration in `backend/main.py` at line 180.

## Impact

A malicious website could make unauthorized requests to the API, potentially leading to data leakage, unauthorized actions, or other security bypasses, especially if authentication mechanisms are misconfigured or have other flaws.

## Technical Analysis

The `CORS` middleware is initialized with `allow_origins=["*"]`, which explicitly enables cross-origin requests from any domain. This is found in `backend/main.py`.

## Proof of Concept

1. Intercept a request to any endpoint on the application.
2. Modify the `Origin` header to a malicious domain.
3. Observe that the request is successfully processed, indicating the permissive CORS policy.

```python
# Example of a malicious request from an arbitrary origin (concept only)
import requests

url = "http://host.docker.internal:8000/api/vehicles"
headers = {
    "Origin": "http://malicious-site.com"
}
response = requests.get(url, headers=headers)
print(response.status_code)
print(response.text)
```

## Code Analysis

**Location 1:** `backend/main.py` (line 180)
  Restrict CORS origins
  ```
      allow_origins=["*"],
  ```

  **Suggested Fix:**
```diff
-     allow_origins=["*"],
+     allow_origins=[], # TODO: Replace with specific trusted origins
```

## Remediation

Restrict the `allow_origins` list in the CORS middleware to only include trusted domains that are expected to access the API. Avoid using the wildcard `*` unless the API is explicitly designed to be publicly accessible and handles no sensitive data or actions.

## Assumptions

Assumes that the application may handle sensitive data or actions where cross-origin restrictions are necessary for security.
