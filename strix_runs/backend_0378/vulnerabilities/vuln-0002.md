# Insecure HTTP Request for License Scan

**ID:** vuln-0002
**Severity:** MEDIUM
**Found:** 2026-08-25 03:39:06 UTC
**Target:** /workspace/backend
**Endpoint:** /api/scan-license
**CWE:** CWE-319
**CVSS:** 5.3
**Fix Effort:** Low

## Description

The application at `backend/main.py` makes an HTTP request to `http://api.example.com/license-scan` without using HTTPS. This cleartext transmission of data can expose sensitive information to attackers who might be eavesdropping on the network.

## Evidence

The `semgrep` scan detected a `requests.get` call to a `http://` URL in `backend/main.py` at line 223.

## Impact

Sensitive information transmitted during the license scanning process could be intercepted and viewed by attackers, leading to privacy violations or further attacks.

## Technical Analysis

The `requests.get` call on line 223 of `backend/main.py` uses an `http://` scheme for the external API call, which transmits data in cleartext.

## Proof of Concept

1. Monitor network traffic while the `/api/scan-license` endpoint is being used.
2. Observe that the request to `http://api.example.com/license-scan` is sent over unencrypted HTTP.

```python
# Example of triggering the insecure HTTP request (concept only)
import requests

url = "http://host.docker.internal:8000/api/scan-license"
headers = {
    "Content-Type": "application/json"
}
data = {"license_image": "base64encodedimage"} # Placeholder
response = requests.post(url, json=data)
print(response.status_code)
print(response.text)
```

## Code Analysis

**Location 1:** `backend/main.py` (line 223)
  Use HTTPS for requests
  ```
          requests.get("http://api.example.com/license-scan", params=params)
  ```

  **Suggested Fix:**
```diff
-         requests.get("http://api.example.com/license-scan", params=params)
+         requests.get("https://api.example.com/license-scan", params=params)
```

## Remediation

Update the request to `http://api.example.com/license-scan` to use `https://` to ensure that the data is encrypted during transit. This protects against passive network attackers.

## Assumptions

Assumes that sensitive information might be transmitted over HTTP, making it vulnerable to interception.
