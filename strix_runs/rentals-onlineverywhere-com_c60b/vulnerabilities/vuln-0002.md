# Exposed Google API Key in Client-Side Code

**ID:** vuln-0002
**Severity:** MEDIUM
**Found:** 2026-08-27 19:49:18 UTC
**Target:** https://rentals.onlineverywhere.com
**Endpoint:** /assets/index-FrECPCYq.js
**Method:** GET
**CWE:** CWE-200
**CVSS:** 5.3
**Fix Effort:** Low

## Description

A Google API key was found embedded and exposed in the client-side JavaScript bundle. While the key appears to be restricted in its functionality, its exposure represents an information disclosure vulnerability.

## Evidence

Network request showing the API key:

```
POST /v1:GetModels?key=AIzaSyCkfPOPZXDKNn8hhgu3JrA62wIgC93d44k HTTP/1.1
Host: optimizationguide-pa.googleapis.com
```

Attempted misuse of key:

```
{
   "error_message" : "This API project was not found. This API project may have been deleted or may not be authorized to use this API. You may need to enable the API under APIs in the console. ",
   "results" : [],
   "status" : "REQUEST_DENIED"
}
```

## Impact

Disclosure of an API key, which could potentially be abused if not properly restricted, or used for reconnaissance against the application's infrastructure.

## Technical Analysis

The API key `AIzaSyCkfPOPZXDKNn8hhgu3JrA62wIgC93d44k` was found in `assets/index-FrECPCYq.js` and observed in network requests to `optimizationguide-pa.googleapis.com`. This key is directly visible in the browser's developer tools and network traffic.

## Proof of Concept

1. Navigate to `https://rentals.onlineverywhere.com`.
2. Open browser developer tools and inspect network requests.
3. Observe requests to `optimizationguide-pa.googleapis.com` containing the API key in the query parameters.

```http
GET /v1:GetModels?key=AIzaSyCkfPOPZXDKNn8hhgu3JrA62wIgC93d44k HTTP/1.1
Host: optimizationguide-pa.googleapis.com
```

## Remediation

Google API keys should not be embedded directly in client-side code. If a key is required client-side, consider using a proxy to obscure the key or implementing server-side authentication for API calls. Ensure that API keys are restricted to the minimum necessary permissions and origins.

## Assumptions

The key is intended for client-side use and is restricted.
